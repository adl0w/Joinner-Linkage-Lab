# Joinner

Joinner is a static browser app for designing and simulating mechanisms. It uses plain HTML, CSS, and JavaScript and does not need a build step or server.

## GitHub Pages

The included GitHub Actions workflow publishes `index.html`, `styles.css`, and `app.js` whenever you push to `main` or `master`.

1. Push this project to a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Set **Build and deployment → Source** to **GitHub Actions**.
4. Push to `main` or `master`, or start **Deploy static site** from the Actions tab.

GitHub Pages will show the published URL in the workflow run and under **Settings → Pages**.

## Run locally

Open `index.html` in a modern browser. No dependencies or local server are required.
